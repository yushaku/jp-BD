# Giới thiệu — page overrides

> Deviations from MASTER only. Palette / type stay MASTER (navy + Lora / Be Vietnam Pro).

---

**Pattern:** Editorial storytelling (hook → journey → proof → CTA)  
**Layout:** Single column, max ~44rem for prose; stats / quotes / values may go wider.  
**Density:** Low — generous whitespace, not a data dashboard.

## Sections

1. Intro hook — oversized title, one lead paragraph  
2. Journey — company story + wide product photo  
3. Proof — values + customer quotes  
4. Climax CTA — shop + contact  

## Do

- One brand hue (`--jp-primary`) for titles, active, buttons  
- Eyebrows uppercase muted  
- Quotes as quiet cards, not rainbow blocks  
- SVG icons, no emoji  

## Don't

- Distinct color per chapter  
- Pink CTA / Noto JP (MASTER forbids)  
- Scale-on-hover layout shift
